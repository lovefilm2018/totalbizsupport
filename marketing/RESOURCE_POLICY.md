# Marketing Resource & Quota Allocation Policy

> **Core Objective:** Maximize business growth and lead generation for TotalBiz Support (`totalbiz.co.uk`) while optimizing token and API credit usage across all AI models and local CLI sessions.

---

## 10 Mandatory Resource Rules

1. **Antigravity CLI Quota Preservation:** Antigravity CLI (AGY) is a premium execution resource. Do not perform heavy, open-ended research tasks in AGY if they can be offloaded to Gemini App (Deep Research) or Google AI Studio.
2. **Model Tier Matching:**
   - **Gemini 3.5 Flash / Light models:** Straightforward file updates, basic formatting, log checks, routine maintenance.
   - **Gemini 3.1 Pro / Heavy reasoning:** Strategic architecture, complex code refactoring, deep problem solving.
   - **Claude / High-tier models:** Unusually difficult brand messaging, nuanced tone reviews, or complex edge cases.
3. **No Redundant Research:** Maintain a permanent record of all research, competitor data, and keyword lists in local Markdown files under `marketing/`. Never re-query AI models for research that already exists in the repo unless data is known to be outdated.
4. **Copy/Paste Instruction Protocol:** Where a task requires human interaction (e.g. creating a Facebook page, posting to Nextdoor, verifying Google Business Profile), AGY will provide Alex with exact, step-by-step copy/paste blueprints in `marketing/05-operations/TODAY.md` rather than burning agent tokens waiting interactively.
5. **Permanent Memory Ledger:** Every strategy decision, target persona, competitor insight, and daily task blueprint must be committed to the `marketing/` directory structure for seamless multi-session continuity.
6. **Task Offloading:**
   - **Gemini Pro App (Deep Research):** Macro market research, competitor analysis, deep strategy drafting.
   - **Google AI Studio (Playground):** Bulk copy generation, ad copy variations, video scripts, long-form content.
   - **Local Aider Model:** Fast text transformations, Markdown cleanup, repetitive local code updates.
   - **ChatGPT:** Independent second opinions and sanity checks on strategic decisions.
7. **Local-First SEO & High-Margin Focus:** Prioritize hyper-local East Sussex SEO and GBP map pack dominance for fast revenue, while maintaining UK-wide remote positioning for high-margin web app and TOM consulting.
8. **Daily Feedback Loop:** After completing daily tasks, Alex feeds back metrics/outcomes into AGY, which records results in `marketing/04-analytics/` and adjusts the active strategy.
9. **No Code Without Purpose:** All landing page changes, SEO updates, and form tweaks on `totalbiz.co.uk` must align directly with active campaigns documented in `marketing/01-strategy/`.
10. **Outcome Per Credit Metric:** Always measure success by real business outcomes (leads, inquiries, local visibility) per unit of AI resource consumed.
11. **Mandatory Session Continuity Synchronization:** Before concluding any turn or session, AGY MUST update `AGENTS.md`, `GEMINI.md`, `Completed.md`, and `TODAY.md` so that future sessions immediately pick up with zero context loss.
